# Skill icon sources

The Devicon SVGs in this folder are from Devicon 2.16.0 and are covered by the accompanying `LICENSE-DEVICON.txt`.

The following brand marks are from Simple Icons:

- Keycloak, Jitsi, GitHub Copilot, and Claude: Simple Icons 16.0.0
- OpenAI: Simple Icons 15.22.0

Simple Icons is distributed under CC0, but its disclaimer notes that individual marks may have separate licenses and trademark rules. The icon metadata lists GitHub Copilot as MIT, Keycloak as custom, and does not specify a license for Jitsi, Claude, or OpenAI. Check each brand's current guidelines and permissions before reuse, especially for commercial purposes. All trademarks remain the property of their respective owners.

SignalR, Entity Framework, FastEndpoints, and Ocelot API Gateway do not have a dedicated icon in the selected icon set; they use the .NET ecosystem icon rather than an invented brand mark.
